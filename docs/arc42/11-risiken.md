# 11. Risiken und technische Schulden

| Risiko                                                                                                | Auswirkung                                                                                | Maßnahme                                                                                                                                |
| ----------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| DB Timetables API (Beta) ändert sich oder fällt aus                                                   | Echte Zugzeiten fehlen                                                                    | Schätzung bleibt mit Hinweis, Adapter austauschbar, Link auf bahn.de                                                                    |
| Fahrpläne nur ~18 h voraus, Umstiege nur einmal                                                       | Spätere Dates nur mit voraussichtlichen Zügen                                             | Akzeptiert; Live-Karte am Tag selbst                                                                                                    |
| Preisänderungen Anthropic/Google                                                                      | Hochrechnung stimmt nicht mehr                                                            | Harte Anbieter-Limits; monatliche Kontrolle laut Runbook                                                                                |
| Google-Nutzungsbedingungen (Caching, Darstellung)                                                     | Verstoß bei Speicherung von Ortsdaten                                                     | Volle Ortsdaten nur bis zum Datum des Plans, danach nur Place-ID + Name; Bedingungen bei Änderungen erneut prüfen                       |
| Claude erfindet lokale Details                                                                        | Falsche Vorschläge                                                                        | Claude erzeugt allgemeine Ideen; konkrete Orte kommen ausschließlich aus Places                                                         |
| Wettervorhersage > 7 Tage unsicher                                                                    | Unpassende Outdoor-Vorschläge                                                             | Hinweis in der UI, Outdoor-Aktivitäten mit Alternative                                                                                  |
| Verlust aller Passkeys                                                                                | Kein Zugang                                                                               | Notfall-Passwort                                                                                                                        |
| Neon Free Tier: Pausieren bei Inaktivität                                                             | Erster Aufruf langsamer                                                                   | Akzeptiert                                                                                                                              |
| Fahrzeiten sind Schätzungen (Luftlinie × Umwegfaktor × Durchschnittstempo)                            | Zeitplan weicht von echten Verbindungen ab                                                | Direktzüge über DB Timetables (ADR-009); Umstiege, Busse und Dates > 16 h voraus bekommen voraussichtliche Züge; Google Routes optional |
| Identity Federation statt statischem Claude-Key nicht umgesetzt                                       | Statischer Key kann leaken                                                                | Schaden durch Workspace-Limit begrenzt; Umstellung auf Vercel-OIDC möglich                                                              |
| Ortssuche liefert nur Treffer um einen Suchmittelpunkt                                                | Stopps „auf dem Weg“ werden seltener gefunden als am aktuellen Ort                        | Akzeptiert; Anteil der Suchen entlang des Wegs als Konstante im Planner anpassbar                                                       |
| Max. 6 Ortsabfragen pro Plan                                                                          | Lange Tage mit vielen Punkten erreichen das Limit, Rest wird mit ortlosen Ideen gefüllt   | Kostenlose Ideen werden zuerst über OSM gesucht (spart Google-Kontingent), zählen aber ebenfalls zum Limit; akzeptiert                  |
| Öffentliche Overpass-API langsam / Rate Limit                                                         | Wartezeit beim Planen                                                                     | Zeitlimit 4 s, Schutzschalter 10 min, Ausweichen auf Google; eigene Instanz/Mirror nur nötig, falls ohne Google betrieben               |
| Voraussichtliche Zugzeiten aus einem anderen Tag (Feiertage, Baustellen, Sonderfahrpläne)             | Geplante Abfahrt stimmt nicht                                                             | Als „expected“ gekennzeichnet; gespeicherte Pläne holen innerhalb von 16 h echte Züge                                                   |
| Nur ein Umstieg, Umstiegsbahnhöfe nur aus Laufwegen                                                   | Verbindungen mit mehreren Umstiegen bleiben geschätzt                                     | Akzeptiert; Link auf bahn.de                                                                                                            |
| Wenige Bewertungen                                                                                    | Gelernte Werte schwanken                                                                  | Glättung mit Pseudo-Bewertungen, Zeitverfall, begrenzte Wirkung der Tag-Gewichte (ADR-014)                                              |
| Wetterlage vergangener Dates nur ~10 km genau, Pläne vor 2026-10-12 ohne Wetterpunkt (Wohnort)        | Lernen je Wetterlage ungenau                                                              | Akzeptiert                                                                                                                              |
| Öffnungszeiten ohne Feiertage (Google liefert nur reguläre Zeiten)                                    | An Feiertagen (z. B. 25.12., 1.5.) kann ein geschlossener Ort eingeplant werden           | Akzeptiert; mögliche Lösung: bayerische Feiertage lokal berechnen und Öffnungszeiten dann als unbekannt markieren                       |
| Reservierte Kosten der Websuche sind eine Schätzung (10.000 Input-Tokens je Suche, nicht verifiziert) | Ein einzelner Ausflug kann das Tagesbudget überschreiten, abgerechnet wird erst danach    | Reservierung mit geloggtem `usage` eines echten Ausflugs vergleichen und bei Bedarf anpassen                                            |
| Ausflüge bekommen nur Direktzüge                                                                      | Hin-/Rückfahrt mit Umstieg bleibt bei Claudes Hinweis                                     | Akzeptiert; die Umstiegssuche der Dates ließe sich nutzen, braucht aber eine Darstellung für Anschlusszüge in der Ausflugsansicht       |
| Zu Fuß oder per Rad mit Start am Zielort, aber Heimweg                                                | Ein weiter Heimweg passt nicht ins Zeitfenster, der Plan fällt auf „Cozy night in“ zurück | Akzeptiert; mit „Staying there“ entfällt der Heimweg                                                                                    |
